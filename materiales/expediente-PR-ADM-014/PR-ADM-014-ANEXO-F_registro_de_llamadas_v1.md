# Anexo F — Registro de llamadas de seguimiento

| Campo | Valor |
| --- | --- |
| Código | PR-ADM-014-ANEXO-F |
| Versión | v1 |

> Material de práctica del taller.

## Formato del registro

| Campo | Descripción |
| --- | --- |
| Fecha y hora | Momento de la llamada |
| Cotización | Número correlativo al que corresponde |
| Resultado | Contactado / No contesta / Solicita más tiempo / Declina |
| Próximo paso | Acción concreta y fecha |
| Registró | Nombre de quien llamó |

## Regla

Toda cotización con monto sobre el umbral de aprobación recibe al menos una llamada de seguimiento
antes de marcarse como vencida.
